สแกนพัสดุเข้าคลัง

หน้าเว็บพร้อมสำหรับเพิ่มระบบสแกน แต่ HAR ที่ได้รับล่าสุดเป็นของ “การจัดการตารางเวลา” และ “พัสดุที่คาดว่าจะเข้าคลัง” ยังไม่มีคำขอ API จากหน้าสแกนจริง จึงยังไม่ส่งบาร์โค้ดเข้าระบบแทนคุณโดยการเดา

เพื่อเชื่อมจริงอย่างปลอดภัย ให้เปิดหน้าสแกนเข้าคลังใน MS แล้วบันทึก HAR หลังทดลองสแกนพัสดุทดสอบ 1 ชิ้น จากนั้นจึงเพิ่มการเรียก API จริงในหน้านี้ได้
