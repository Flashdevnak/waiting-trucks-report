# Waiting Trucks Report BNAK

ระบบใช้ฟรี: GitHub Pages เป็นหน้าจอ, Google Apps Script เป็น API และ Google Sheet เก็บข้อมูล/ประวัติ

## จุดที่เพิ่ม

- อัปโหลด Excel จากเว็บโดยตรง ไม่ต้องคัดลอกไปวางในชีต
- ปุ่มลงเสร็จสิ้นและลบ โดยยังเก็บประวัติตรวจสอบ
- รถที่ดำเนินการแล้วจะไม่กลับมาเมื่ออัปโหลดไฟล์ซ้ำ
- หยุดนับเวลา 00:00–01:00, 07:00–08:00, 10:00–15:00 และ 18:00–19:00
- ค้นหา กรอง ประวัติย้อนหลัง มือถือ และรีเฟรชทุก 30 วินาที
- หน้า `ms.html` สำหรับติดตามเส้นทาง MS แบบอ่านอย่างเดียว แยกสิทธิ์ตาม HUB
- ตัวเชื่อม `ms-sync.user.js` อ่านข้อมูลจากเซสชัน MS บนเครื่องพนักงานและซิงก์ทุก 30 วินาที โดยไม่ส่งคุกกี้ MS ไปเก็บภายนอก

## เปิดใช้ backend ครั้งแรก

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. วางเนื้อหา `apps-script/Code.gs` แทนโค้ดเดิม
3. รัน `setupSystem('รหัสที่ต้องการ')` เช่น `setupSystem('55555')` และอนุญาตสิทธิ์
4. เลือก **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
5. ตั้ง **ดำเนินการในชื่อ: ฉัน** และ **ผู้มีสิทธิ์เข้าถึง: ทุกคน**
6. นำ URL `/exec` ใหม่ไปแทน `CONFIG.apiUrl` ใน `main.js`

## เปิดใช้หน้าติดตามเส้นทาง MS

1. อัปเดตและ Deploy `apps-script/Code.gs` เป็นเวอร์ชันใหม่ เพื่อเพิ่มชีต `ระบบ_ติดตามเส้นทาง_MS` และ API `msRoutes` / `syncMsRoutes`
2. ติดตั้ง Tampermonkey บนเครื่องที่เปิด MS แล้วนำไฟล์ `ms-sync.user.js` ไปสร้างเป็น UserScript
3. เปิดหน้า `บันทึกสถานะเส้นทางเดินรถสาขาที่เกี่ยวข้อง` ใน MS และเข้าสู่ระบบตามปกติ
4. กด `เชื่อมต่อ` ที่กล่องมุมขวาล่าง แล้วใช้ Username/รหัสจัดการของระบบรถรอลงงาน ระบบจะจำเฉพาะ session token และจะไม่เก็บรหัสผ่าน
5. เปิด `ms.html` จากเมนู `ติดตามเส้นทาง MS` ข้อมูลจะรีเฟรชทุก 30 วินาที

ตัวเชื่อมอ่านข้อมูลเท่านั้น ไม่เรียก API แก้ไขสถานะใน MS และไม่ส่ง `ms-sid` หรือ `ms-uuid` ไปยัง Google Apps Script

ระบบสร้างชีต `ระบบ_รถรอลงงาน`, `ระบบ_ประวัติ` และ `ระบบ_บันทึกการใช้งาน` โดยไม่แก้หรือลบชีตเดิม
